# 🌱 Sprout

**De la idea al código en un clic.**

Sprout es una plataforma "Mobile First" para desarrolladores que elimina la fricción entre tener una idea brillante y configurar el entorno de desarrollo. Actúa como un gestor de ideas que se conecta con tu cuenta de Git para generar repositorios y estructuras base (boilerplates) de forma automatizada.

## 🚀 Características Core (MVP)
* **Bandeja de Entrada Rápida:** Captura título, descripción y stack tecnológico fácilmente desde tu móvil.
* **Kanban de Estados:** Organiza el ciclo de vida de tus proyectos (Idea > Esqueleto Montado > Desarrollo > Pruebas > Producción).
* **Git Automation (Magic Button):** Crea un repositorio y despliega la estructura inicial del proyecto automáticamente vía API.

## 🛠️ Stack Tecnológico (MVP)
* **Frontend:** Next.js + React
* **Estilos:** Tailwind CSS (Enfoque Mobile First)
* **BaaS (Auth & Base de datos):** Supabase (PostgreSQL) + GitHub OAuth
* **Integración:** GitHub REST API
